# Simulación del Sistema Solar

Proyecto de simulación numérica 3D de la dinámica gravitatoria del Sistema Solar.

## Objetivos

- Implementar un modelo gravitatorio N-body.
- Utilizar condiciones iniciales reales.
- Estudiar la estabilidad y evolución orbital.
- Analizar diferentes métodos de integración numérica.
- Estudiar posteriormente la evolución de la masa del Sol.
